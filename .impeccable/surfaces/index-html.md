## Direction contract

THESIS: The app earns "built for a kid, not a school portal" — refusing the generic ed-tech default (flat grey cards, thin blue links, a digital-clock timer) for a warm, rounded, game-like shell with real elevation and a committed accent per region, so a sequence of math drills reads as leveling up rather than filling out a form.

OWN-WORLD: Paper-blue ground (#F5F7FF) with a grid-paper tint (#E2E7FA) reserved for the equation-notebook surfaces; white cards carry either a soft long shadow for floating panels or a same-hue 1px ring for resting cards — never both on one element. Fredoka is the display face for headings and big numbers; Rubik carries body text and Hebrew UI copy. Large corner radii (28/18/12px). Five accent roles each do a real job: blue for primary actions and selection, orange for energy/streaks, mint for correct/success, sun for coins and rewards, pink for the parent/admin surfaces (purple stays rare, for a single standout moment). Signature move: the chunky button — a 4px solid offset shadow in the button's own darker shade that compresses flat under the content on press.

STORY: A student opens the app and recognizes it as theirs, not a school system; every correct answer, earned coin, and passed sheet feels tactile because of the pressed-button language and the color each state owns. A parent opens the dashboard into the same shell at calmer density — one system, a different task.

FIRST VIEWPOINT: The topic header becomes a blue-ground bar with a white Fredoka greeting and chunky pill actions (change password, log out). Below it, the practice-track grid becomes same-height chunky cards in flat accent fills drawn from the five-role palette (replacing the old per-track CSS gradients, which are exactly the decorative-tile pattern this system refuses), titled in Fredoka, keeping each track's existing emoji as content/wayfinding rather than inventing a custom icon system. Primary actions (start a sheet, submit an answer) use the chunky blue button; the coins readout becomes a sun-colored pill badge.

FORM: seed: none (unavailable) — direction pinned by the user's own CSS tokens, not rolled.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
